What it masks

Seven kinds of data. One placeholder.

Every match becomes ⟦kind:abc•••⟧: the model still knows what was there, you still know which value it was.

01 · key

API keys & tokens

OpenAI, Anthropic, Stripe, GitHub, AWS, Google, Slack, JWTs, Bearer tokens, private key blocks and any long mixed token.

sk-ant-… → ⟦key:sk-•••⟧
02 · secret

Passwords & secrets

Values of PASSWORD=, api_key:, *_TOKEN and the password in user:pass@host URLs. Env lookups stay.

PASSWORD=hunter2 → PASSWORD=⟦secret:hun•••⟧
03 · email

Email addresses

Any address, Unicode letters included.

josé@müller.de → ⟦email:jos•••⟧
04 · phone

Phone numbers

International formats and native numerals: Arabic, Persian, Devanagari.

+39 333 123 4567 → ⟦phone:+39•••⟧
05 · card

Card numbers

13 to 19 digits, with spaces or dashes.

4111 1111 … → ⟦card:411•••⟧
06 · iban

IBANs

Every country, spaces optional.

DE89 3704 … → ⟦iban:DE8•••⟧
07 · id

National IDs

Nine countries, switchable from /config.

RSSMRA85T10A562S → ⟦id:RSS•••⟧
— · left alone

Not secrets

Dates, times, IP addresses, years, prices and ports. Pasted logs stay readable.

192.168.1.20 → 192.168.1.20
How it works

A safety net between Enter and the model.

One hooks module, running inside Claude Code on the exact text you are about to send.

1

You press Enter

prompt.submit fires before the prompt enters the session. Slash commands pass through untouched.

2

It masks locally

Matches become placeholders. The engine, the model, the stored transcript and other plugins only see the masked text.

3

It fails closed

If the check ever breaks, the prompt is dropped instead of being sent unmasked.
